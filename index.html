M.D. Sky OS

Multi-role logistics operations platform

mdskyos.com (opens in new tab) ↗

React · JavaScript · Supabase · PostgreSQL · Google OAuth · Cloudflare · GitHub

  • Architecture. Four role-specific applications — owner, dispatcher, driver, customer — over one shared set of shipment records.
  • Identity & access. Google OAuth sign-in, with database security policies restricting reads and writes by role and ownership: drivers reach only assigned loads, customers only their own shipments.
  • Workflow. Shipment request → dispatcher assignment → driver status updates from a phone → current status for owner and customer.
  • Testing. End-to-end browser QA per role, including permission tests that confirm refused actions are actually refused.
  • Change & deployment. Every change tracked in Git and deployed on Cloudflare with a custom domain and DNS; rollback to the last working version when a release breaks a workflow.
