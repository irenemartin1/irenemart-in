How I work an issue

  1. People first, then priorityWho’s blocked and what work has stopped. A branch that can’t check out books outranks one user’s setting.
  2. See the whole systemTrace account → permissions → device → network/DNS → application → data, and what else a change would touch.
  3. Reproduce & isolateExact error, time and recent changes. Sign in as the affected role and test one variable at a time.
  4. Unblock, then fix properlyGet the person working first, with a creative workaround if needed. Then the permanent fix, with rollback ready.
  5. Close the loopConfirm with the user, document cause and fix, and escalate when it’s past my access.

I learn fast. Insurance sales rep → operations systems manager for 80 people → building and supporting live software. Each step meant learning new tools on the job, quickly, while people depended on them.
